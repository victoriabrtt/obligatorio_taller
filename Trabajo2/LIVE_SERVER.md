# Usando Live Server

Si estás utilizando Visual Studio Code, la extensión "Live Server" es una manera fácil de servir archivos web:

1. Instala la extensión Live Server desde el Marketplace de VSCode
2. Abre el archivo `index.html` en VSCode
3. Haz clic derecho en el archivo y selecciona "Open with Live Server"

Esto abrirá automáticamente la página en tu navegador predeterminado.
